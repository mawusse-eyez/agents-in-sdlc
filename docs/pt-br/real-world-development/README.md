Explore o GitHub Copilot ao longo do ciclo de vida de desenvolvimento de software usando cenários realistas, um aplicativo completo e um backlog compartilhado. Você trabalhará de forma iterativa para planejar alterações, criar código, testar comportamentos, revisar pull requests e gerenciar trabalho com agentes.

## Cenário

Você é um novo desenvolvedor da Tailspin Toys, uma empresa fictícia que oferece financiamento coletivo para jogos de tabuleiro com tema de desenvolvimento. O backlog da equipe já está registrado em issues do GitHub e pronto para você começar. Ele inclui trabalho de funcionalidade, como filtragem e paginação, além de melhorias de qualidade, como acessibilidade e padrões de codificação.

## Escolha seu ambiente

O GitHub Copilot atende você em qualquer ambiente em que você trabalhe. Escolha o ambiente que mais combina com a forma como você quer construir. Cada workshop começa com sua própria configuração e usa o mesmo cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente baseado em agentes no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, Playwright MCP, Agent Merge e comandos de barra práticos.

### [Aplicativo GitHub Copilot][app]

Execute sessões paralelas de agente, altere os modos de sessão, colabore em telas e gerencie issues e pull requests do GitHub no aplicativo desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente seu trabalho, acompanhe o progresso e revise as pull requests que ele abrir.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
